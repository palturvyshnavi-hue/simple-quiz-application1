# Simple Quiz Application

A simple command-line Quiz Application developed using Python.

The application asks multiple-choice questions and calculates the user's
score and percentage at the end of the quiz.

## Features

- Multiple-choice questions
- Four options for each question
- Input validation
- Automatic score calculation
- Percentage calculation
- Result message
- Case-insensitive answers
- Object-Oriented Programming
- Unit testing using Python unittest
- Easy to run in VS Code
- Ready to push to GitHub
